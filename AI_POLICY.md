# Using AI here

**Short version: AI is allowed. Submitting code you cannot explain is not.**

Most of us use these tools. Pretending otherwise would be silly. But this project exists so
that people understand algorithms, and code that appears without understanding does not help
anyone.

## Fine

- Asking it to explain a paper, a derivation, or an error you are stuck on.
- Asking it to review your code or find a bug.
- Getting a first draft, then reading it properly and making it your own.
- Boilerplate, docstrings, formatting.
- Checking your English.

## Not fine

- Submitting code you have not read.
- Submitting a derivation you did not follow. If you cannot redo the steps on paper, it is not
  yours yet.
- **References you never checked.** These tools invent papers that do not exist. Every source
  you list must be one you actually opened.
- Opening five algorithm pull requests at once. Those get closed.

## What we ask

The pull request template has a checkbox for AI use. Tick it if you used it. It costs you
nothing and it is not held against you.

There is also a short box asking you to explain, in your own words, what your code does and one
choice you made. Write that part yourself. It is usually the moment you notice something you
have not fully understood, which is a good thing to find out.

A reviewer may ask you about any line. A plain answer is all that is needed. "I am not sure,
let me go read it again" is a perfectly good answer, and your pull request stays open while you
do.

## Why we care

You will graduate. The tool will still be there. The time you have right now to sit with
something until it clicks is the part that runs out.

Use the tool. Do not skip the understanding.
